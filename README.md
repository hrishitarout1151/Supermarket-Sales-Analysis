## Supermarket Sales Analysis
An end-to-end data analytics project analyzing real retail transactions to uncover sales, profit, and customer behavior patterns across three supermarket branches.
Built with Python for data cleaning/EDA and Tableau for interactive visualization.
## 📊 About the Project

This project analyzes 1,000 real point-of-sale transactions from a supermarket chain operating three branches, covering a 3-month period.
The goal was to build a complete BI workflow — from raw data to a decision-ready interactive dashboard — the same pipeline used in real analytics/BI roles.

## Dataset source: Supermarket Sales — Kaggle (by aungpyaeap).
Real transactional data from a Myanmar-based supermarket chain, Jan–Mar 2019, 3 branches (Yangon, Mandalay, Naypyitaw).

🛠️ Tech Stack
Python (pandas, numpy, matplotlib) — data cleaning, feature engineering, exploratory data analysis
Tableau — interactive dashboard design and business storytelling
Jupyter Notebook — analysis documented cell-by-cell for full transparency

## 🔍 What Was Done
- Data Cleaning (Python): standardized column names, parsed date/time fields, removed duplicates, validated data types
- Feature Engineering: derived profit margin %, average item price, hour-of-day, day/month fields for deeper slicing
- Exploratory Data Analysis: analyzed sales trends, product line performance, regional distribution, payment behavior, and customer demographics
- Dashboard Design (Tableau): built 9 individual visualizations plus one combined interactive dashboard with:
  KPI summary cards (Total Sales, Gross Income, Average Rating, Transactions)
  Daily sales trend across all 3 branches
  Product line performance (sales vs. profit comparison)
  City-wise sales share and payment method breakdown
  Customer demographics and hourly sales patterns
  Cross-filtering and click-to-highlight interactivity

## Key Outcomes / Insights
- Identified which product lines drive sales volume vs. which drive profit margin — they aren't always the same, a key inventory/pricing insight.
- Found peak sales hours and days, useful for staffing and promotional timing decisions.
- Compared performance across all 3 branches to flag under/over-performing locations.
- Analyzed payment method preference and customer type (Member vs. Normal) behavior to inform loyalty program decisions.
